一個可以執行的小例子

使用第一筆虛構行程，選第二個出發日期。這些類別也用在商品列表與詳情頁。

// 把範例資料建立成套裝行程，再交給旅行社保存。
const product = createProduct(SAMPLE_TOURS[0]);
const agency = new Agency("AGENCY-01", product.agency);
agency.addProduct(product);

// 用商品編號找到商品，選第二個梯次，讀取它的價格。
const found = agency.findProduct("TOUR-001");
const departure = found.quoteAt(1);
departure.priceLabel;
五個報告重點
封裝PriceQuote 用 #amount 保存金額，外面透過 getter 讀取；建立時拒絕負數。
繼承三種商品 extends TravelProduct，共用名稱與梯次。
多型商品卡都呼叫 getSummary()，由各子類別回傳自己的摘要。
擁有旅行社內有商品，商品內有梯次，梯次內有報價。
限定鍵Agency.findProduct(productId) 只查該旅行社的商品集合，找不到回傳 null；這不是登入權限驗證。
簡短資料字典
Agencyid、name：字串；products：以商品編號查找的 Map。
TravelProductid、title、agencyId：字串；departures：梯次陣列。
Departuredate、returnDate：YYYY-MM-DD 字串；quote：PriceQuote 物件。
PriceQuoteamount：非負數字或 null；feeText：費用說明字串。null 表示未知價格。
