# 獨立畫面提案

下載儲存庫 ZIP、解壓縮，開啟 `index.html`，即可查看畫面。

**[程式碼流程圖與對照](flow.html)**：開啟後查看；`程式碼流程圖.puml` 是可編輯原稿，`CodeFlow.svg` 是圖檔。

**[類別圖與對應程式](objects.html)**：四種主要物件、一張圖、一個可執行例子；`models.js` 是展示頁實際使用的類別，`商品類別圖.puml` 為原稿。

- `index.html`：聊天輸入區與商品列表。
- `detail.html`：商品詳情、出發日期及聯絡入口。
- `style.css`：桌面與手機樣式。
- `app.js`：固定範例資料、物件與畫面互動，附中文註解。
- `models.js`：旅行社、商品子類別、梯次與報價；示範封裝、繼承、多型、擁有及限定鍵。
- `sample-tours.js`：50 筆虛構套裝行程，10 家範例旅行社、150 筆出發日報價；組員可直接修改。

套裝行程預設顯示六筆，按「顯示更多行程」逐批展開。另保留一筆機加酒與一筆機票作為分類示例。

參考方向：TourRadar 的一致商品資訊、Travelstride 的旅遊建議，以及 TravelSupermarket 的業者轉接。

目前可操作分類、填入標籤、查看詳情與切換範例出發日。聊天、商品與聯絡窗口皆為畫面提案，未串接 AI、真實業者或付款；正式整合位置待確認。
