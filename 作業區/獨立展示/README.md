# 獨立展示：先看這裡

下載 ZIP 並解壓縮後，開啟 **[index.html](index.html)**，從中文入口選擇要看的內容。

| 資料夾 | 放什麼 | 什麼時候看 |
| --- | --- | --- |
| [01_展示網頁](01_展示網頁) | 首頁、商品詳情 HTML | 想看網站或改畫面上的文字 |
| [02_前端程式碼](02_前端程式碼) | 物件、操作流程、配色樣式 | 想改功能或解釋程式 |
| [03_範例資料](03_範例資料) | 50 筆虛構行程與日期報價 | 想改商品名稱、日期、價格 |
| [04_UML圖表](04_UML圖表) | 程式流程、商品類別、MVC 循序 | 想看圖、改圖或準備上台 |

每個資料夾都有簡短的 README 說明。圖表的 `.puml` 是原稿，`.svg` 是圖片，`.html` 是看圖說明頁。

目前可操作分類、填入標籤、查看詳情、切換範例日期。資料均為虛構，未串接 AI、資料庫或真實業者。
